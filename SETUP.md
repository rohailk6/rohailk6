# Publish your profile

The files are prepared for the existing public repository `rohailk6/rohailk6`.
`README.previous.md` preserves the README downloaded before these changes.

1. Open `preview.html` in a browser to review the artwork. Reload to replay it.
2. Open https://github.com/rohailk6/rohailk6 and choose **Add file → Upload files**.
3. Upload `README.md`, `portrait.svg`, `info-card.svg`, `contrib-heatmap.svg`, `profile.json`, and the `scripts`, `data`, and `assets` folders. Commit the changes. These replace your profile's current appearance.
4. Create `.github/workflows/update-profile-art.yml` using **Add file → Create new file** and paste the contents of the matching local file. (The `.github` folder is hidden in Finder.) Commit it.
5. Open **Actions → Update profile art → Run workflow**. Confirm the run succeeds. Scheduled runs are set for 06:17 UTC / 11:17 Pakistan time; GitHub may delay scheduled runs.

You can keep `preview.html`, `SETUP.md`, and `README.previous.md` locally; they aren't required for the public profile.

## Customize

Edit `profile.json`, then regenerate all three SVG files locally:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install Pillow
python scripts/build_profile.py
python scripts/build_extras.py
```

The portrait uses `assets/portrait-source.png`, copied from your supplied transparent Subject.png cutout. It preserves the entire subject and maps transparency to empty space. Replace this file and regenerate to change the portrait. The ASCII conversion is deterministic; no image-generation service is used.

The daily job runs `python scripts/build_profile.py --heatmap-only` and needs no third-party dependencies or personal access token. GitHub's automatic workflow token supplies permission to commit the generated files. Repository or organization policies and branch protection can restrict these writes.

The contribution scraper reads GitHub's public HTML calendar, not a stable API. If its markup changes, the generator fails rather than replacing the graph with empty data. Review failed workflow runs and update the parser when needed. Private contribution details are not fetched.

Artwork has a visible static fallback and honors reduced-motion preferences. Verify the final animation on your GitHub profile after publishing; this local preview cannot validate GitHub's rendering or caching.

The welcome banner, stack panel, project cards, and contact panel are generated by `scripts/build_extras.py`. Edit its text to customize those panels, then rerun it. Upload the generated SVGs in `assets/` along with the README.
